# SoleSync Website

Public web pages for **SoleSync**, an iOS app for tracking shoe mileage
for runners, walkers, and hikers.

This site is hosted with GitHub Pages and provides the URLs required
for App Store submission.

## Pages

- Privacy Policy: https://jkercheval.github.io/SoleSync-site/privacy.html
- Support: https://jkercheval.github.io/SoleSync-site/support.html

## Updating the privacy policy

1. Edit `privacy.html`.
2. Update the "Last updated" date at the top of the policy.
3. Commit and push to `main`. GitHub Pages republishes automatically
   within a few minutes.

If the policy changes in a way that affects how data is collected or
used, also review the App Privacy answers in App Store Connect.
